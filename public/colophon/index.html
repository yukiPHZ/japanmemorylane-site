Japan Memory Lane

写真と言葉の、静かな記憶。

Japan Memory Laneは、旅先の案内ではなく、日本に残る小さな光景や感触を、写真と短い言葉のあいだに置く場所です。

急いで説明せず、記憶が記憶のままでいられる余白を残すために作っています。

制作しているのは、菊田 幸彦（Yukihiko Kikuta）です。写真と言葉を通して、日本の静かな記憶を残しています。

写真の扱いPhoto handling

選んだ写真は、ことばをつくるためにOpenAI APIへ送信されます。Japan Memory Laneでは、写真を作品一覧やアカウントとして保存しません。

OpenAIの現行案内では、APIへ送信されたデータは既定ではモデル学習に使われません。不正利用の監視のため通常最大30日保持される場合があり、法令や安全上の理由による例外があります。

Selected photos are sent to the OpenAI API to create the poems. Japan Memory Lane does not keep them as an account or public gallery.

OpenAI currently states that API data is not used for model training by default. Abuse monitoring data may normally be retained for up to 30 days, with exceptions for legal or safety reasons.
